# StructuresPlus (Paper 26.3)

Ameliore toutes les structures generees :
- bonus de ressources dans tous les coffres de structures (table `chests/*`) + remplissage des coffres vides
- vieillissement (briques moussues/fissurees, mousse) sur ruines, strongholds, temples, etc.
- toiles d'araignee dans les structures sombres
- details de village : lanternes sur les barrieres, fleurs

Commandes : `/structuresplus reload`, `/structuresplus scan [rayon]` (permission `structuresplus.admin`)

Build : push sur GitHub, le workflow Actions compile le jar (artefact `StructuresPlus`).
